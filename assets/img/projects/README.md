# Capturas de Proyectos (`assets/img/projects/`)

Coloca aquí las capturas o imágenes de vista previa de tus juegos y proyectos (formato recomendado: `.png` o `.webp` en proporción aproximada `16:9` o `16:10`, por ejemplo `800x450 px`).

Nombres ya preconfigurados en `assets/js/data.js`:
- `lior-dungeon-crawler.png` → Vista previa para **Lior Dungeon Crawler**
- `mantis-parry.png` → Vista previa para **Mantis Parry**

Si un archivo aún no existe en esta carpeta o la propiedad `image` está en `null`, la tarjeta del proyecto mostrará automáticamente la vista previa representativa con el emblema y color oficial de su división.
